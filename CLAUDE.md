Этот проект Shiny приложение для управление нашим Windows сервером и расположенными на нём задачами и скриптами.

# Архитектура приложения
Всё приложение разбито на модули, 1 модуль это 1 вкладка интерфейса:

1. Задачи - основная вкладка с которой мы работаем, на неё выводится информация о задачах настроенных в планировщике заданий Windows. тут мы работаем с упавшими скриптами, смотрим их логи и так далее.
2. Службы - настроенные нами службы на сервере в том числе и само это приложение
3. AI асситент - Вкладка с AI чатом который помогает писать код и работать со скриптами на сервере
4. Поиск по файлам - Вкладка для поиска файла со скриптом.
5. CMD - Интерфейс командной строки
6. Доступ - Управление пользователями приложения
7. Логи - Логи использования приложения
8. README и NEWS - Информационные вкладки

# Работа с Git

Перед тем как отправить push убедись что ты изменил версию в файле appl_info.yaml, что описание доработок внесено в NEWS.md и внесено согласно стандартам этого файла:

Коммит который привязан к релизу определённой версии должен быть с прикреплённым ярлыком с номером версии, что бы его было легче потом найти в истории.

Все изменения в NEWS.md распределены по блокам Added, Fixed, Changed, версия подписана номер - дата, без автора это не надо.

Комментарий к последнему перед push коммиту после самого push уходит как описание изменений в сообщение в telegram канал нашего отдела, поэтому составляй его так же как если бы ты делал анонс изменений в канале нашего отдела.

Приложение разделено на 2 папки:

1. "C:\scripts\alsey\netpeak_core\nc_analytics_team\shiny_task_service_manager (dev)" - используется для разработки, все изменения внедряются и тестируются тут
2. "C:\scripts\alsey\netpeak_core\nc_analytics_team\shiny_task_service_manager" - продакшен папка, сюда изменения попадают только через git push в master репозитория из dev папки

# Как добавлять новый функционал

После любой доработки приложения проверяй README.md, если в приложение что то изменилось обязательно эту часть актуализируй и в README, если добавилось то добавь это в описание. 
Очень важно всегда держать README в актуальном состоянии.
